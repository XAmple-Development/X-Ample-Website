## Overview

Turns utility trucks into fully operational rigs (bucket controls, stabilizers, synced actions).

Store page: `/store/package/6829241`

## Resource name

The store description references:

```
ensure xample-utility
```

## Requirements

- OneSync enabled
- `ox_lib` (recommended per description)

## Install

1. Download and extract into `resources/`.
2. Add to `server.cfg`:

```
ensure ox_lib
ensure xample-utility
```

3. Restart server.

## Usage

- Spawn code (from description): `utillitruck4`

## Configuration

- Adjust bucket speeds/limits, light patterns, and leg deployment in the config file.

## Troubleshooting

### Bucket controls don’t work

- Verify OneSync is enabled.
- Ensure `ox_lib` is started before this resource.
