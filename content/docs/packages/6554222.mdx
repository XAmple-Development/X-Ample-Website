## Overview

Custom loading screen resource (HTML-based) with configurable sections.

Store page: `/store/package/6554222`

## Resource name

Most installs use:

```
ensure x-ample_loading_screen
```

## Install

1. Download and extract into `resources/`.
2. Add to `server.cfg`:

```
ensure x-ample_loading_screen
```

3. Restart server.

## Configuration

Common configuration location:

- `html/loadscreen.html`

You can customize:
- background image(s)
- menu button labels/links
- music/audio sources

## Troubleshooting

### Loading screen is blank

- Check console for missing file paths.
- Ensure your server is serving the resource correctly (folder name matches `ensure`).
