## Overview

Discord Rich Presence integration for your FiveM server.

Store page: `/store/package/6377209`

## Resource name

Most installs use:

```
ensure xample_presence
```

## Install

1. Download and extract into `resources/`.
2. Add to `server.cfg`:

```
ensure xample_presence
```

3. Restart server.

## Configuration

Typically configured in a client file (often `client.lua`):

- Discord application Client ID
- Presence text / buttons
- Update interval

## Troubleshooting

### Presence not updating

- Confirm the Discord application Client ID is correct.
- Ensure players have Discord running.
