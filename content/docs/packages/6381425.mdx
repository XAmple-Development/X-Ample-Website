## Overview

Adds a bus-driving job with routes, stops, and payouts.

Store page: `/store/package/6381425`

## Resource name

Your download folder name is the source of truth. A common naming pattern is:

```
ensure xample_busjob
```

If the folder is named differently, update the `ensure` line to match.

## Install

1. Download and extract into `resources/`.
2. Add to `server.cfg`:

```
ensure xample_busjob
```

3. Restart server.

## Configuration

- Routes/stops/timings are typically in `config.lua`.
- Balance payouts to match your economy.

## Troubleshooting

### No routes show

- Check your route config and ensure coordinates are valid.
