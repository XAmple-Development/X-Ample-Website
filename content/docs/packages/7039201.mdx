## Overview

NON-ELS emergency vehicle package.

Store page: `/store/package/7039201`

## Install (typical vehicle resource)

1. Download and extract into `resources/`.
2. Ensure the resource in `server.cfg` (resource name is the folder name you installed):

```
ensure <resource_folder_name>
```

3. Restart server.

## Usage

- Vehicle spawn codes are usually listed in the included README or inside the vehicle meta files.

## Troubleshooting

### Vehicle not spawning

- Ensure the resource is started.
- Confirm you’re using the correct spawn name.
- If your server uses a vehicles.lua/shared vehicles list, add the vehicle there.
