## Overview

Adds a laundromat interior (MLO) resource to your server.

Store page: `/store/package/6668188`

## Resource name

Most installs use:

```
ensure xample_laundromat
```

## Install

1. Download and extract into `resources/`.
2. Add to `server.cfg`:

```
ensure xample_laundromat
```

3. Restart server.

## Troubleshooting

### Interior not loading

- Ensure the resource started successfully.
- Check for streaming conflicts with other map packs affecting the same area.
