## Overview

Remastered `qb-taxijob` with an AI hail-a-taxi system.

Store page: `/store/package/7042348`

## Resource name

Most servers keep the original resource name:

```
ensure qb-taxijob
```

If your download folder is different, `ensure` the folder name you installed.

## Requirements

- QB-Core
- PolyZone
- Optional (depending on your setup): `qb-inventory`, `qb-management`, `qb-banking`

## Install

1. Download and extract into `resources/`.
2. Add to `server.cfg`:

```
ensure qb-taxijob
```

3. Restart server.

## Usage

- AI taxi command (from description): `/hailtaxi`
- Cancel command: `/canceltaxi`

## Configuration

- Prices and behavior are usually in `config.lua`.

## Troubleshooting

### AI taxi never arrives

- Check PolyZone and route/pathing constraints.
- Make sure `qb-target` / interaction requirements (if any) are installed.
