## Overview

X-Ample + is a subscription that unlocks access to a set of included packages.

Store page: `/store/package/6375796`

## How access works

- After subscribing, download packages from your Tebex library.
- Some packages may be delivered via FiveM escrow (Asset Escrow System).

## Install included packages

Each included package has its own docs page under `/docs/package/<id>`.

General steps:

1. Download the package from Tebex.
2. Extract into `resources/`.
3. Add `ensure <resource_name>` to your `server.cfg`.
4. Restart server.

## Troubleshooting

### I subscribed but can’t download

- Confirm you are logged into the same Tebex account you used for purchase.
- Allow a few minutes for entitlement sync.
- If still missing, contact support via Discord.
