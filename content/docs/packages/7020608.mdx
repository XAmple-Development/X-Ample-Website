## Overview

Retexture pack for 24/7 shop interiors.

Store page: `/store/package/7020608`

## Resource name

The store description references:

```
ensure x-ample_247_shop
```

## Install

1. Download and extract into `resources/`.
2. Add to `server.cfg`:

```
ensure x-ample_247_shop
```

3. Restart server.

## Troubleshooting

### Textures don’t change

- Clear client cache.
- Check for conflicts with other texture packs touching the same assets.
