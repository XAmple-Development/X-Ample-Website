## Overview

Modern scoreboard / player list UI with configurable identifiers and Discord webhook integration.

Store page: `/store/package/6610756`

## Resource name

The store description references:

```
ensure xample-playerlist
```

## Install

1. Download and extract into `resources/`.
2. Add to `server.cfg`:

```
ensure xample-playerlist
```

3. Restart server.

## Configuration

Common config location (from description):

- `nui/config.json`

Typical settings:
- open key
- identifiers shown
- Discord webhook URL (if supported)
- UI theme settings

## Troubleshooting

### UI doesn’t open

- Confirm the configured open key and check for conflicts.
- Clear client cache and restart FiveM.
