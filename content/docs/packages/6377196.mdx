## Overview

Enhanced crouch mechanic (standalone).

Store page: `/store/package/6377196`

## Resource name

Most installs use:

```
ensure xample_crouch
```

## Install

1. Download and extract into `resources/`.
2. Add to `server.cfg`:

```
ensure xample_crouch
```

3. Restart server.

## Configuration

- If configurable, set crouch keybind and any movement/weapon restrictions.

## Troubleshooting

### Animation glitches

- Check for conflicts with other movement/stance resources.
