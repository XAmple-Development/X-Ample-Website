## Overview

Shows player IDs above characters with a toggle command.

Store page: `/store/package/6377187`

## Resource name

Most installs use:

```
ensure xample_ids
```

## Install

1. Download and extract into `resources/`.
2. Add to `server.cfg`:

```
ensure xample_ids
```

3. Restart server.

## Configuration

- Adjust display range and duration in the config (commonly a `distance` and timeout setting).

## Troubleshooting

### IDs don’t show

- Confirm the resource started.
- Try the command (commonly `/ids`) and check chat/console for errors.
