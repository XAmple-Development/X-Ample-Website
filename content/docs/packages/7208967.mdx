## Overview

Priority-based queue with Discord role rewards, reconnect boosts, and a dynamic queue UI.

Store page: `/store/package/7208967`

## Resource name

The store description references:

```
ensure x-ample_queue
```

## Requirements

- Discord bot token + server ID + role IDs (for priority)
- OneSync recommended

## Install

1. Download and extract into `resources/`.
2. Add to `server.cfg`:

```
ensure x-ample_queue
```

3. Restart server.

## Configuration

Typical config files:

- `config_discord.lua`: bot token, guild id, role ids, priority points
- `config.lua`: identifier rules, maintenance mode, reconnect boost, UI text/links, ETA toggle

## Troubleshooting

### Queue UI shows but priority not applying

- Confirm the bot has permission to read member roles.
- Verify role IDs are correct.
