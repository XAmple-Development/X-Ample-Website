## Overview

Mining gameplay system (mining, washing, cracking, crafting) built for QB-Core style servers.

Store page: `/store/package/6553179`

## Resource name

Most installs use:

```
ensure x-ample_mining
```

## Install

1. Download and extract into `resources/`.
2. Add to `server.cfg`:

```
ensure x-ample_mining
```

3. Restart server.

## Configuration

- Configure locations, items, recipes, and selling points in `config.lua`.
- If SQL is included, import it into your database.

## Troubleshooting

### Interactions don’t work

- Check target/interaction dependency requirements (commonly `qb-target` / `ox_target` / `ox_lib` depending on build).

### Missing items / crafting fails

- Ensure required items exist in your inventory database/config.
- Re-check recipe definitions in `config.lua`.
