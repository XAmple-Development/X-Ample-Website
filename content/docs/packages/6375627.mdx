## Overview

This package is a UI overhaul for a QB banking resource.

Store page: `/store/package/6375627`

## Resource name

Most installs use:

```
ensure qb_banking_ui_overhaul
```

## Requirements

- QB-Core stack (recommended)
- The banking resource this UI replaces/extends (read the included README in your download)

## Install

1. Download from Tebex.
2. Extract into `resources/`.
3. Add to `server.cfg`:

```
ensure qb_banking_ui_overhaul
```

4. Restart server.

## Configuration

- Follow the included setup instructions in the download.
- If there’s a config file, you can usually adjust:
  - colors/theme
  - text labels
  - locale/currency display (your site pricing is USD, so validate in-game displays if the UI assumes GBP)

## Troubleshooting

### UI doesn’t load / NUI errors

- Clear client cache and restart FiveM.
- Ensure any required banking resource is started before this overhaul.

### Styling looks broken

- Check for missing build steps (some UI resources ship prebuilt; others require a build—read the included README).
