## Overview

Modern standalone chat UI replacement.

Store page: `/store/package/6375776`

## Resource name

Most installs use:

```
ensure xample_chat
```

## Install

1. Download and extract into `resources/`.
2. Add to `server.cfg`:

```
ensure xample_chat
```

3. Restart server.

## Configuration

- Many chat resources include UI settings (colors, fonts, positioning). Check the included config.

## Troubleshooting

### Chat doesn’t appear

- Ensure no other chat resource is still running.
- Clear client cache and restart FiveM.
