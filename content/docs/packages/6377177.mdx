## Overview

Standalone ragdoll toggle (key/command varies by config).

Store page: `/store/package/6377177`

## Resource name

Most installs use:

```
ensure xample_ragdoll
```

## Install

1. Download and extract into `resources/`.
2. Add to `server.cfg`:

```
ensure xample_ragdoll
```

3. Restart server.

## Usage

- Common defaults:
  - Key: `U`
  - Command: `/ragdoll`

Check your config if it differs.

## Troubleshooting

### Keybind doesn’t work

- Check keybind conflicts and confirm resource started.
