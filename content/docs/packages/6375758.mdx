## Overview

Allows players to sit on chairs across GTA V/FiveM.

Store page: `/store/package/6375758`

## Resource name

Most installs use:

```
ensure x-ample_chair
```

## Install

1. Download and extract into `resources/`.
2. Add to `server.cfg`:

```
ensure x-ample_chair
```

3. Restart server.

## Troubleshooting

### No interaction prompt

- Make sure the resource started successfully.
- Test with a clean client cache.
