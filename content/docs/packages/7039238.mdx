## Overview

Prison alarm system + guards for immersive prison gameplay.

Store page: `/store/package/7039238`

## Resource name

The store description references:

```
ensure xample-prison
```

## Install

1. Download and extract into `resources/`.
2. Add to `server.cfg`:

```
ensure xample-prison
```

3. Restart server.

## Usage

- Command (from description): `/prisonalarm`

## Troubleshooting

### Command doesn’t work

- Ensure you have permissions (if restricted).
- Confirm the resource started successfully.
