## Overview

Lets players piggyback each other using a command.

Store page: `/store/package/6377201`

## Resource name

Most installs use:

```
ensure xample_piggyback
```

## Install

1. Download and extract into `resources/`.
2. Add to `server.cfg`:

```
ensure xample_piggyback
```

3. Restart server.

## Usage

- Common command: `/piggyback` (run again to cancel)

## Troubleshooting

### Players desync / stuck animations

- Ensure OneSync is enabled.
- Check for conflicts with emote/animation resources.
