## Overview

Taxi driver job with NPC passenger pickups and payouts.

Store page: `/store/package/7041014`

## Resource name

The store description references:

```
ensure xample-taxijob
```

## Install

1. Download and extract into `resources/`.
2. Add to `server.cfg`:

```
ensure xample-taxijob
```

3. Restart server.

## Configuration

- Configure fares, spawn points, and job rules in the config file.

## Troubleshooting

### No passengers spawn

- Check spawn locations and ensure they’re not inside blocked interiors.
- Confirm OneSync is enabled if required.
